## 4. Модель данных и функции

createTasks - содает объект задачи 
при успехе - объект с свойствами ok: true и объектом задачи task с нужными свойствами
при ошибке - объект с свойствами ok: false и текстом ошибки под error

findTaskById - ищет задачу с заданным id
при успехе - индекс в массиве
при ошибке - undefined

getPendingTasks - фильтрует массив от выполненных задач
при успехе - новый отфильтрованный массив
при ошибке - пустой массив 

getTaskTitles - возвращает имена задач
при успехе - массив с названиями задач
при ошибке - пустой массив

getTaskStats - возвращает статистику по задачам
при успехе - объект с свойствами: количество задач, количество выполненных задач, количество невыполненных задач, прогресс
при ошибке - объект со всеми значениями равны 0

addTask - добавляет задачу в список
при успехе - новый массив с новой задачей в конце
при ошибке - сообщение с ошибкой

setTaskCompleted - изменяет статус задачи
при успехе - новый массив с изменной статусом у задачи
при ошибке - сообщение с ошибкой

renameTask - переименовывает название задачи
при успехе - новый массив с изменным названием у задачи
при ошибке - сообщение с ошибкой

removeTask - удаляет задачу из списка
при успехе - новый массив без удаленной задачи
при ошибке - сообщение с ошибкой

**Почему id не равен индексу:** потому что id это свойство объекта, а индекс это номер значения в массиве.  
**Почему getTaskStats возвращает число, а не строку с процентом:** потому что число процента легче вернуть, так как не надо ничего преобразовывать, а также с числом лечге работать в будущем, например для сравнение результатов, а если надо строка то можно его преобразовать вне функции.  
**Какие объекты копируются при изменении задачи:** все объекты, которых изменение не затронули.
